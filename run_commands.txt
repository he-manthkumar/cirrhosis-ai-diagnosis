Cirrhosis AI Diagnosis - Run Commands (PowerShell)

1) Open project
cd d:\Finalyearproject\cirrhosis-ai-diagnosis

2) Database setup
Already configured to SQLite in .env:
DATABASE_URL=sqlite:///./cirrhosis.db
No PostgreSQL setup needed.

3) Create virtual environment with Python 3.12
py -3.12 -m venv .venv

4) Install dependencies
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install -r requirements.txt

5) Start backend API
.\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload

--- Open a second terminal for frontend ---

6) Start frontend static server
cd d:\Finalyearproject\cirrhosis-ai-diagnosis\frontend
python -m http.server 5500

URLs
API Docs: http://127.0.0.1:8000/docs
Frontend: http://127.0.0.1:5500

Optional (only if you get "models not trained yet")
cd d:\Finalyearproject\cirrhosis-ai-diagnosis
.\.venv\Scripts\python -m scripts.train_model
